# LockNote v1.0.7 Release Notes

Release Date: June 14, 2026

## New Features

### Editor Line Numbers
- Added optional line numbers on the left side of the note editor.
- Added a line-number toggle at the end of the Markdown toolbar.
- Added a settings option to persist whether editor line numbers are shown.

### Settings Dialogs
- Password changes now open in a focused dialog instead of expanding inline on the settings page.
- Auto-lock configuration now opens in a dialog for a cleaner settings layout.
- Theme and language settings were moved above the password section for quicker access.

## Improvements

### Markdown Editor
- Restored split mode so the editor and preview panes appear side by side when selected.
- Kept the Markdown toolbar available behind the editor header toggle while adding the line-number control.

### Settings Page
- Reduced visual clutter by moving password and auto-lock details into dialogs.
- Kept security, appearance, and language controls grouped in a clearer order.

## Compatibility

- This version keeps the existing local data format compatible with previous 1.0.x releases.
- Existing notes, todos, images, settings, and backups are preserved.
